    ด่าน 1

    ภารกิจ

    เรียงกล่องจากน้อยไปมาก โดยไม่ให้จำนวนการสลับเกินที่กำหนด คลิกกล่องใบแรก แล้วคลิกใบที่สองเพื่อสลับ

    ทุกการสลับนับเป็นหนึ่งครั้ง ถ้าสลับหมดโควตาแล้วยังไม่เรียง ด่านจะล้มเหลว

    ความรู้ที่ได้จากด่านนี้

    สายพานแคบ (สลับได้เฉพาะกล่องติดกัน): จำนวนสลับที่น้อยที่สุดเท่ากับจำนวนคู่ที่เรียงผิดลำดับ ซึ่งเป็นจำนวนที่ Bubble Sort ใช้

    เครนยกกล่อง (สลับคู่ไหนก็ได้): Selection Sort หยิบค่าที่ถูกต้องมาวางทีละตำแหน่ง จึงสลับน้อยมากและไม่เกิน n−1 ครั้ง

    ปุ่มคำใบ้จะบอกว่า Algorithm ตัวนั้นจะเลือกสลับคู่ไหนต่อไป

    เปรียบเทียบ 0 สลับ 0
    เลือกคู่แข่งแล้วกด “เริ่มแข่ง” คุณสลับกล่องได้ทุกคู่ ส่วน Algorithm ต้องทำทีละขั้น (เปรียบเทียบนับเป็นหนึ่งขั้น)

    กติกา

    กล่องชุดเดียวกันวางบนสายพานสองเส้น เรียงจากน้อยไปมากให้เสร็จ ก่อน Algorithm จะเรียงเสร็จ

    Algorithm ทำงานตามขั้นตอนจริงของมัน (ใช้ฟังก์ชันเดียวกับห้องฝึก) ไม่ได้โกง ไม่ได้เร่งเป็นพิเศษ

    เคล็ดลับ

    คุณเปรียบเทียบด้วยสายตาได้ฟรี แต่ Algorithm ต้องเสียเวลาทุกครั้งที่เปรียบเทียบ ลองใช้แนวคิดแบบ Selection Sort: หาค่าที่ควรอยู่ตำแหน่งแรก แล้วสลับเข้าไปทีเดียว

    ห้องวิเคราะห์

    ภารกิจ

    ดูลักษณะของกล่องและเป้าหมายของโรงงาน แล้วทายว่า Algorithm ไหนทำได้ดีกว่า

    หลังตอบ เกมจะรัน Algorithm ทั้งสองตัวจริงๆ แล้วนับจำนวนครั้งให้ดู ตอบถูกได้รอบละ 20 แต้ม

    ข้อควรจำ

    Algorithm ไม่มีตัวไหนดีที่สุดเสมอไป ขึ้นกับ รูปแบบของข้อมูล และ สิ่งที่เราอยากประหยัด (การเปรียบเทียบหรือการสลับ)

    วิธีเล่น Sorting Factory

    เป้าหมายคือเรียงกล่องจาก น้อยไปมาก และเข้าใจว่า Algorithm คิดอย่างไรถึงเรียงได้

    ห้องฝึก

    กด “ขั้นถัดไป” ดู Bubble Sort และ Selection Sort ทำงานทีละขั้น พร้อมคำอธิบายและบรรทัดโค้ดที่กำลังทำงาน

    ปริศนาโรงงาน

    6 ด่าน คุณเป็นคนสลับกล่องเอง แต่มีโควตาการสลับจำกัด ใช้ดาวบอกความเก่ง (ดาวสามดวงคือสลับน้อยที่สุดและไม่ใช้คำใบ้)

    แข่งกับ Algorithm

    เรียงชุดเดียวกันให้เสร็จก่อน Algorithm

    ห้องวิเคราะห์

    ทายว่า Algorithm ไหนเหมาะกับข้อมูลและเป้าหมายที่โจทย์ให้ แล้วดูตัวเลขจริง
